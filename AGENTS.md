## Agent skills

### Issue tracker

Issues and PRDs use local Markdown under `.scratch/`; external pull requests are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Use `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a multi-context repository. Read the root `CONTEXT-MAP.md` and the relevant context glossaries and ADRs. See `docs/agents/domain.md`.
